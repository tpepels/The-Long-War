# Shipped runtime and research decks

`decks/index.json` catalogues the shipped deck profiles. Each listed JSON file supplies match input to the runtime and research consumers; `src/longwar/decks.py` validates construction.

These strategic profiles differ from the exploratory physical combination decks in `cards/playtest-decks.json`. The latter are the public print-and-play package and are documented in `cards/playtest-decks.md`.

| Profile | Source |
| --- | --- |
| Mobility / Open Bonds | `decks/mobility-open-bonds.json` |
| Persistent Elite / Heroes | `decks/persistent-elite-heroes.json` |
| Narrative / Command | `decks/narrative-command.json` |
| Battlefield Control / Stratagems | `decks/battlefield-control-stratagems.json` |
| Momentum / Orders | `decks/momentum-orders.json` |
| Necessity / Attrition | `decks/necessity-attrition.json` |

Membership lives in JSON, not in this guide. Names describe intended deck identity; they are not current balance verdicts. Runtime/research support is being synchronized separately, so old deck-inclusion statistics and pre-overhaul strength results must not be used as current evidence.
