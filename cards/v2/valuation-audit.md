# V2 command-cost valuation audit

This audit applies the provisional arithmetic in `value-model.md` to **every one of the 128 V2 cards**. The numbers are comparative diagnostics, not automatic pricing: class synergy, topology and repeatability are too contextual for a single scalar to set final Command cost.

- **IN BAND**: estimated value is within ±0.9 of the type/cost target.
- **HIGH / LOW**: review candidate, not an automatic nerf/buff.
- Repeatable ACTION text pays an Action tax.
- Conditional/reference-heavy effects are discounted for applicability.
- Every new 0-Command Order is scored with its eligibility restriction included.

## Interpretation

The table makes pricing discussions reproducible. A flagged card should still be checked against actual playability and telemetry before changing its cost. A narrow card can score correctly on expected value while still being unfun because it is dead too often; **condition-active rate remains a separate metric**.
