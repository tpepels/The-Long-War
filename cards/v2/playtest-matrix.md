# V2 playtest and archetype matrix

This is a **test-coverage document**, not a deck list and not a balance ranking.

The redesign should not be judged only by whether classifications have enough cards. We also need a broad enough mechanical pool to build contrasting decks and learn which effects are fun, legible, targetable, worth their Command, and worth spending an Action on.

These categories overlap. A card may exercise several mechanics.

## What to test before adding more cards

The current 95-card pool already covers enough different mechanics to run meaningful tests. The first goal should **not** be to optimize six finished constructed decks. We want decks that deliberately expose different systems.

1. **Build vs disruption** - leadership/building against Raider/Skirmisher suppression and prepared-card interference.
2. **Protection vs pressure** - Guard/Veteran resilience against hostile Tactics and Strength pressure.
3. **Information vs hidden plans** - Scout/Seer information against Stratagem-heavy play.
4. **Command risk** - both decks contain expensive payoffs, discounts, taxes, and recovery so we can see whether Command decisions are real.
5. **Mobility control** - one Rider-heavy deck versus a deck with almost no movement to measure whether movement is actually valuable.
6. **Baseline control** - a deliberately boring, efficient deck with plain Forces/Bonds. If synergy decks cannot beat or outplay it, the fancy mechanics are not earning their complexity.

For every card, the playtest should record at minimum:

- drawn;
- played;
- dead in hand / no legal or worthwhile target;
- Command spent;
- Action spent;
- whether its effect materially changed a decision or Front result;
- whether the opponent had meaningful counterplay;
- whether a marker or rule was forgotten;
- whether the card caused a rules question;
- whether the player would voluntarily include it again.
