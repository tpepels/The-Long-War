# Artwork authoring originals

These uncropped illustration originals are retained for future physical card artwork edits. Selected, normalized production illustrations live in `web/art/cards/<card-id>.png` and are the sole artwork input to the Pages build.

This directory is outside `web/` and is never deployed. Alternative source crops are not additional production card mappings. The old candidate tree duplicated these files byte-for-byte and has been removed.
