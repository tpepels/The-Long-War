# SVG icon collection — The Long War

This is a **copy-only archive** of existing inline SVG icons from the current `main` branch. It does not change the physical card designs, CSS, game logic or live icons. The source currently contains **no standalone .svg files**; icons are generated by `web/card-symbols.js` and inserted by `web/physical-cards.js`.

## Summary

- **card-types:** 8 variants, 8 in use.
- **classifications:** 18 variants, 18 in use.
- **utility:** 24 variants, 9 in use.
- **rows:** 4 variants, 4 in use.
- **command:** 6 variants, 0 in use.
- **decorative:** 1 variants, 1 in use.

Only the `card-types`, `classifications`, active timing `utility` icons and `rows` are rendered in current physical card faces. Other utility definitions and numeric Command variants are collected for preservation, but are not currently invoked by the physical-card renderer. The setup-map SVG is decorative, not an icon; the inspection-only Pages build hides the Webgame.

The source shape geometry is unchanged. SVG color uses `currentColor`; direct viewing may differ from how site CSS colors the icons. The row-icon copies explicitly indicate filled ranks because their `row-active` CSS class was supplied by the original page. No artwork was redesigned.

See [index.html](index.html) for a visual gallery and [manifest.json](manifest.json) for source file/line references.
