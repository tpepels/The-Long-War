# Historical reports

These dated reports preserve earlier design decisions and engineering context. They are not current card wording, rules, runtime documentation, or balance evidence. In particular, old Subject/Story terminology, Retreat-era rules, card counts and deck quotas describe the revision tested at the time.

Start with `WORKSTREAMS.md`, `README.md` and `ARCHITECTURE.md` for active development. Use `cards/cards.json` and `rules/rulebook.md` for the physical game. Current research evidence must match the implemented game fingerprint; the Balance Lab distinguishes stale evidence from usable results.
