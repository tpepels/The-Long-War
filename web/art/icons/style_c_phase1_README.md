# The Long War — Style C icon pack (phase1)

This archive uses the same repository directory structure as the earlier icon packs.
Extract it at the repository root to place the icons under `web/art/icons/` and the size variants under `web/art/icons/sizes/`.

## Included icons

force, guard, archer, healer, bond, name, action, reaction

## Variants

Each icon includes:
- original transparent PNG at `web/art/icons/<name>.png`
- size variants at 16, 24, 32, 48, 64, 128, 256, and 512 px

These are Style C exploration assets and do not automatically change the live SVG implementation.
