The Long War V2 card lab

Mechanical redesign preview

The old card face, rebuilt for persistent stacks.

The V2 mechanics keep the original Long War parchment, typography, frame, seals, and restrained heraldic treatment. The only structural change is the exposed top edge: Strength, classifications, timing/state icons, and any recurring reminder remain readable when cards are stacked. Command cost moves to the bottom.

This page renders the proposed 95-card V2 set only. It is not the engine card pool and it does not use the current decks.

Physical grammar

What remains visible

  • Force: base Strength + classifications + buried recurring reminder.
  • Bond: signed modifier + classifications + compact recurring reminder.
  • Name: signed modifier + full visible ability text.
  • Cost: bottom-right, because it matters in hand rather than in the stack.
  • Memory: anything not obvious from the table gets a used/effect marker.
